Requesting External Data

How Do We Request Data?

  • Everything on the internet communicates through HTTP
  • Each time we click a link, an HTTP request is sent
  • The server responds with data (HTML, JSON, images, etc.)

What is AJAX?

  • Asynchronous JavaScript And XML
  • Allows sending HTTP requests without reloading the page
  • Used to load data dynamically
  • Makes modern web applications possible

Why Use AJAX?

  • Pages do not reload when new data is needed
  • Faster and smoother user experience
  • Dynamic content loading
  • Efficient communication with servers

AJAX Data Flow

  • Client sends a request
  • Server processes the request
  • Server sends back a data package
  • Client handles and displays the data

JSON

What is JSON?

  • JavaScript Object Notation
  • Lightweight data format
  • Used for sending and receiving data
  • Easy for humans and machines to read

Why JSON?

  • Standard format for data exchange
  • Works across different systems and languages
  • Commonly returned by APIs
  • Perfect for AJAX communication

JSON & JavaScript

  • JSON text can be converted to JavaScript objects
  • JavaScript objects can be converted to JSON
  • This allows easy data manipulation in applications

APIs

What are APIs?

  • Application Programming Interface
  • Server applications for communication
  • Provide access to data or functionality

API Characteristics

  • Used as an interface to data
  • Can be public or private
  • Some require authentication (API keys)
  • Return data, usually in JSON format

Using APIs with AJAX

  • Send HTTP requests from JavaScript
  • Receive JSON data
  • Process and display data dynamically
