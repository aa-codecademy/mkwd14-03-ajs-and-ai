How Is Everything Parsed?

Parsing & Execution

  • JavaScript is executed line by line
  • The browser reads HTML from top to bottom
  • When it reaches a <script> tag, JavaScript starts executing

JavaScript Execution

  • The browser engine executes JavaScript code
  • Each browser has its own JS engine
  • Example: Chrome uses V8

Where Is JavaScript Executed?

The JavaScript Thread

  • JavaScript runs on a single thread
  • Only one operation can execute at a time
  • Blocking code can freeze the page

How the Browser Helps

  • The browser provides additional APIs
  • These APIs handle time-consuming tasks
  • JavaScript delegates work to the browser

Browser APIs

  • setTimeout / setInterval
  • HTTP requests (AJAX / Fetch)
  • DOM events
  • Web storage

Event Queue & Event Loop

Task Queue

  • Completed async tasks are queued
  • Callbacks wait in the queue
  • They wait for the call stack to be empty

Event Loop

  • Monitors the call stack and task queue
  • Moves tasks to the call stack when possible
  • Controls execution order

Event Loop Responsibilities

  • Decides when JS runs
  • Handles asynchronous callbacks
  • Triggers screen rendering

Callback Functions

What Are Callback Functions?

  • Functions passed to other functions
  • Executed after some task finishes
  • Common in async operations

Callbacks & Asynchronous Code

  • Used with browser APIs
  • Executed through the event loop
  • Help prevent blocking the main thread
