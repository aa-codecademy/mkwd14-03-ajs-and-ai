Why Are Functions Important?

  • Easy representation of human concepts in code
  • Organizing logic and data easily
  • Reusability of code
  • Cleaner and more readable applications

Function Components

  • Parameters – input data
  • Return value – output data
  • Function body – logic
  • Can be called multiple times

Calling Functions

  • Functions can be called from anywhere
  • They always execute at the same definition point
  • Helps avoid code duplication

Function Types

Anonymous Functions

  • Functions without a name
  • Used when we need a function on the spot
  • Commonly passed as parameters
  • Often used in callbacks

Arrow Functions

  • Shorter syntax for anonymous functions
  • Easier to read and write
  • Very common for callbacks
  • Not recommended for object methods

Self-Invoked Functions (IIFE)

  • Functions that execute immediately
  • Used only once
  • Run inside a closed scope
  • Helps avoid global scope pollution

Recursion

What is Recursion?

  • Functions can call other functions
  • A function can call itself
  • This behavior is called recursion

Recursive Functions

  • Must have a stopping condition (fail-safe)
  • Prevents infinite function calls
  • Common in tree and nested structures
