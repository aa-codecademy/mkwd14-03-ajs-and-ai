Functions as First-Class Citizens

  • Functions can be used as any other entity
  • They are treated like variables
  • They can be passed, returned, or stored

What Can We Do With Functions?

  • Store them in variables
  • Pass them as parameters
  • Return them from other functions
  • Use them as object properties

Functions as Parameters

  • Functions can be passed to other functions
  • Commonly used for callbacks
  • Allows flexible and reusable logic

Functions as Return Values

  • Functions can return other functions
  • Enables dynamic behavior
  • Common in advanced patterns

Functions in Variables

  • Functions can be stored in variables
  • Variables can be reassigned
  • Helps create flexible code structures

Arguments

  • Arguments represent values passed to functions
  • Functions can accept any number of arguments
  • Useful for generic functionality

What Are Higher Order Functions?

  • Functions that accept other functions
  • Or return other functions
  • Used for complex and reusable logic

Why Use Higher Order Functions?

  • Cleaner and shorter code
  • Better readability
  • Functional programming style
  • Logic can be chained

Common Higher Order Functions

  • filter()
  • map()
  • reduce()
  • sort()

Chaining Higher Order Functions

  • Multiple higher order functions can be chained
  • Each function transforms the data
  • Builds complex logic step by step
