The this Keyword

What Is this?

  • this points to the current object
  • Used to access object properties and methods
  • Its value depends on how a function is called

this in Object Methods

  • Points to the object the method belongs to
  • Works as expected with the function keyword
  • Commonly used in object-oriented code

this in Arrow Functions

  • Arrow functions do not have their own this
  • They inherit this from the surrounding scope
  • Can cause unexpected behavior in objects
